# Ref Session

Lightweight reference-photo sessions: three.js viewer, real-size non-destructive crop, grid advisor.
Static site — `index.html` + `app.js`. Nothing is uploaded; photos stay on the device.

- `npm run build` bundles `src/main.js` (+ three) into `app.js`
- `npm run dev` serves on http://localhost:8421
- iPad: open the https URL in Safari → Share → Add to Home Screen (launches full screen, works offline)
